
# 구인 유료 시스템 - 5만원 선불 + 4.5만원 성과제

## 구조
- 구인: 5만원 결제 후 등록 (30일)
  - 1건: 5만원
  - 5건: 20만원 (건당 4만원)
  - 무제한: 30만원/월
- 구직: 무료

- 채용 성공 시: 4.5만원 추가 (총 5만원)
- 구직자 신고 보상: 5만원 포인트 (신고 유도)

## 파일
app/api/jobs/route.ts - 구인구직 CRUD
app/api/jobs/hire-confirm/route.ts - 채용 확정 + 4.5만원 청구 + 5만원 축하금
app/api/jobs/payment/route.ts - 구인 결제 검증
app/jobs/register/page.tsx - 등록 + 결제
app/jobs/page.tsx - 목록 + 채용 확정 버튼

## 적용
1. 파일 복사
2. prisma schema Job 모델 추가
3. db push
4. 배포

## 프로세스
1. 기업: 구인 등록 → 5만원 결제 → 공고 표시
2. 구직자: 지원 → 면접
3. 기업: 채용 확정 버튼 클릭 → 4.5만원 추가 결제 요청 + 구직자 5만원 축하금
4. 구직자가 취업 신고해도 4.5만원 청구 (5만원 축하금으로 유도)

선불 5만원으로 떼일 걱정 없음!
